# AI Football Predictor Pro — V13.0 Sprint 1

Sportsbook Builder AI Foundation, built on V12.1 Engine Stabilization.

Key changes:
- Over/Under 3.5 promoted into Best Market and Builder intelligence.
- Asian Handicap / Draw No Bet available as single markets only.
- Asian Handicap is explicitly blocked from Bet Builder legs.
- Builder is template-based, not brute-force.
- Builder Portfolio returns at most 3 validated builders per fixture.
- Builder DNA, quality score, risk, EV, sportsbook compatibility, and activation thresholds are included.
- V12.1 single-decision architecture remains intact.

Deploy with Render using `render.yaml`. Keep secrets such as API keys and passwords in Render environment variables.
